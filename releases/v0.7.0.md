Vflow 0.7.0 is an early macOS beta for Apple silicon running macOS 14 or later.

- On-device speech recognition and text cleanup, with models included
- Hold-to-dictate and hands-free shortcuts
- Personal dictionary with JSON import and export
- Local dictation history, dashboard, and recording indicator
- Clipboard fallback when insertion cannot be confirmed

Dictation works without an internet connection. Approximate RAM usage reported by the maintainer is 800–950 MB; usage varies by workload and Mac.

Installation: open the DMG, drag Vflow to Applications, and grant Microphone, Accessibility, and Input Monitoring permissions.

This build is ad-hoc signed and not notarized. If macOS blocks it, use Privacy & Security → Open Anyway after attempting to launch it. If you trust the download, the README also documents the app-specific quarantine command.

Known limitations: recordings are capped at 60 seconds, the system default microphone is used, and native model output has not yet passed parity testing against the project's Python benchmark. When Vflow reports Copied, check the destination before pasting manually to avoid duplicate text.
